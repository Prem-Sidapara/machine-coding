## 🛠️ Getting Started

To run any of the projects locally:

1. **Clone the repository**
   
   git clone https://github.com/Prem-Sidapara/machine-coding.git
   cd machine-coding
   

2. **Navigate to project folder**
   
   cd 01/gradient-generator # (or any project folder)
   

3. **Install dependencies & run dev server**
   
   npm install
   npm run dev

## 🧰 Tech Stack

- **Framework:** React
- **Build Tool:** Vite
- **Styling:** Tailwind CSS
- **Routing:** React Router DOM
- **Icons:** React Icons
- **Date & Time:** Day.js
- **Data Fetching:** Axios
